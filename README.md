# Ezequiel Fontana — Portfolio personal

Portfolio personal de Ezequiel Fontana para presentar su perfil, formación, habilidades y proyectos de desarrollo.

## Tecnologías

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Funcionalidades

- Diseño responsive.
- Menú adaptable para pantallas pequeñas.
- Filtro de proyectos por categoría.
- Galerías de imágenes de proyectos con miniaturas interactivas.
- Formulario de contacto con validación, mensajes de error y contador de caracteres.

## Cómo visualizar el proyecto

Abrí `index.html` directamente en un navegador o ejecutalo con la extensión **Live Server** de Visual Studio Code.
